# AI Agent Workspace Rules

## Commands

- Dev Server: `npm run dev`
- Build Project: `npm run build`

## Context & Architecture

- Next.js 16 App Router architecture with TypeScript and Tailwind CSS.
- Database access MUST use `pool` imported from `@/lib/db`.
- Authentication MUST use helpers from `@/lib/auth`.
- Always check folder structure before introducing new utility files or pages.
